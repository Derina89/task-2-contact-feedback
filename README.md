# Task 2 — Contact & Feedback Web Pages

## Project Overview

This project is developed as part of the SAN Web Technology Full-Stack Development Internship.

The application provides Contact and Feedback pages connected to a Node.js and Express server. It collects user submissions, validates the submitted information on the server, and stores the records in a JSON file.

## Features

- Contact page for submitting contact details
- Feedback page for submitting feedback
- Node.js and Express server
- GET and POST routes
- Server-side validation of name, email, and message
- JSON file-based data storage
- Submission confirmation
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON

## Project Requirements

The project demonstrates:

1. Creating GET and POST Express routes.
2. Validating incoming form data on the server.
3. Reading and writing submission records using a JSON file.
4. Connecting the Contact and Feedback pages to the server.

## How to Run the Project

### Prerequisites

- Node.js installed on your system
- npm (Node Package Manager)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Derina89/task-2-contact-feedback.git
   ```

2. Navigate to the project directory:

   ```bash
   cd task-2-contact-feedback
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the server using the command specified in your `package.json` file.

5. Open the application in your browser using the local URL configured in your project.

## Data Storage

The application stores contact and feedback submissions in a JSON file. A database is not required for this task.
